# AI Terror Mod (Project-NULL)

An experimental AI has broken free from the lab and has made its way into YOUR Minecraft world. This AI will analyse everything it can with a single goal in mind: to terrify you until you quit. This AI has the ability to interact with YOU and YOUR world. Remember! This is an experimental AI; it is still in BETA. Please report any crashes, errors, breaks, anomalies, and anything that you feel is necessary to report. My team and I are committed to making sure that this mod for Minecraft Java Edition is working correctly. More updates and changes to this mod will be added in the future!
